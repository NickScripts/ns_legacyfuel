# Security

If you find a fuel-payment, pump-lock, transaction-validation or other security-sensitive issue, please do not publish an exploit proof in a public issue first.

Instead, contact the project maintainer privately with:

- A short description
- Reproduction steps
- Relevant server/client console output
- Your FiveM/FXServer build if relevant

Security fixes should be tested against both the normal gameplay path and malicious client input.
